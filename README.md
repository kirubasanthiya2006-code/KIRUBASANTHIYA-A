# InternReview AI - Internship Review Automation System

An AI-powered web platform designed to automate the internship project review process, connecting coordinators, interns, and an AI review bot through a single responsive website.

## Tech Stack
- **Frontend**: React.js / Tailwind CSS / Lucide Icons
- **Backend**: Python FastAPI
- **Database**: PostgreSQL
- **AI Integration**: LLM API for automated rubric evaluation & code feedback

## Quick Start
1. Run backend: `uvicorn main:app --reload`
2. Run frontend: `npm start`
3. Open `index.html` for the standalone MVP frontend demo.
